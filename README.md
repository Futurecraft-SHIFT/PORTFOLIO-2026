# Alexandre Bersia — Digital Creative Director Portfolio V1

This is a separate, parallel portfolio direction tailored to Meta's Creative Strategist profile. It remains focused on digital products, culture, world-building, play and creative systems.

The principal addition is **MOTION, SHARED.**, an independent speculative META × CINELLI creative-strategy case positioned between Movement and Systems. It preserves the original Cinelli Aero Visor silhouette and integrates only a flush central camera concept.

See `META-CINELLI-CREATIVE-DIRECTION.md` for the visual analysis, strategy, originality guardrails and responsible-AI framework.

The approved and published CUPRA/automotive portfolio is not modified by this project.

## Preview

Serve this directory from any static local server, then open `index.html` through that server. The Ricard Pétanque game is embedded under `games/ricard-petanque.html` and is loaded only when the visitor chooses to play.
