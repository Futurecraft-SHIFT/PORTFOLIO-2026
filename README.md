# Alexandre Bersia — Digital Creative Director Portfolio V1

This is a separate, parallel portfolio direction focused on digital products, culture, world-building, play and creative systems.

The approved and published CUPRA/automotive portfolio is not modified by this project.

## Preview

Serve this directory from any static local server, then open `index.html` through that server. The Ricard Pétanque game is embedded under `games/ricard-petanque.html` and is loaded only when the visitor chooses to play.

## Content architecture

See `CONTENT-PLAN.md` for the narrative ownership, current material and priority gaps.

## Main files

- `index.html` — narrative layout
- `style.css` — preserved V2.4 visual foundation
- `digital-director.css` — parallel portfolio visual layer
- `script.js` — animation, project manifest, modals and game portal
- `assets/` — selected image and video material
- `games/ricard-petanque.html` — standalone playable experience
